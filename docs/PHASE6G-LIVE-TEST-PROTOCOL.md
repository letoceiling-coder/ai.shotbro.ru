# Phase 6G — протокол реальных тестов (минимальные затраты)

**Разрешение заказчика (2026-10-30):** реальные генерации для теста — с минимальными затратами: видео не длиннее 5 с, озвучка тоже короткая. Тема — рекламная кампания сайта **shotbro.ru**. Лица и голоса реальных людей не используются (ведущий — сгенерированный вымышленный портрет).

## 1. Что проверяем и сколько стоит

Цены — из каталога OpenRouter на 2026-10-30 (бесплатные запросы `GET /videos/models`, `GET /images/models/{id}/endpoints`), ElevenLabs — кредиты платного тарифа.

| # | Шаг | Провайдер / модель | Параметры | Оценка |
|---|---|---|---|---|
| 1 | Первый кадр сцены + портрет вымышленного ведущего | OpenRouter `bytedance-seed/seedream-5-0-flash` | 2 изображения, 9:16, 1K | ≈ $0.04 |
| 2 | Видео сцены | OpenRouter `x-ai/grok-imagine-video-1.5-lite` | 5 с, 480p, без звука, первый кадр из шага 1 | ≈ $0.11 |
| 3 | Озвучка | ElevenLabs `eleven_multilingual_v2`, голос из каталога | 49 символов ≈ 3,5 с | ≈ 50 кредитов (~$0.01) |
| 4 | Видео с аватаром (говорящая голова) | OpenRouter `heygen/avatar-iv` | фото из шага 1, реплика 40 символов ≈ 3 с, 720p | ≈ $0.25 (5¢/с) |
| 5 | Монтаж | наш сервер (ffmpeg) | клип + аватар + озвучка | $0 |
| | **Итого** | | | **≈ $0.41** |

**Не входит в этот прогон:**
- клонирование голоса (IVC) — нужна запись и письменное согласие реального человека (например, владельца бренда); проводится отдельно, когда запись будет;
- фото-аватар HeyGen API — нет `HEYGEN_API_KEY`; по цепочке заказчика (HeyGen → Fal → OpenRouter) аватарное видео идёт через OpenRouter `heygen/avatar-iv`;
- Fal — нет `FAL_API_KEY`;
- апскейл (Magnific) — не нужен для проверки цепочки.

## 2. Защиты, которые действуют во время окна

| Защита | Где |
|---|---|
| Любой платный шаг — только «цена → подтверждение»; сервер сверяет `payloadHash` перед созданием задания | API `CanvasService.start` |
| Лимиты: **$1 на запуск, $3 на пользователя в день** | `evaluateBudgetCaps` при расчёте цены |
| Видео и озвучка **≤ 5 с**: длительность клипа обрезается сервером, текст озвучки/аватара > 70 символов отклоняется | `CANVAS_LIVE_MAX_SECONDS=5` |
| Перед каждым сетевым вызовом воркер заново проверяет: approval, режим, все флаги | `liveCanvasBlockers` + `isApproved` |
| Задание, оценённое в тестовом режиме, не выполняется в живом (и наоборот) | воркер, `MODE_CHANGED` |
| Нет автоповторов платных вызовов (BullMQ `attempts: 1`), ID задания провайдера сохраняется до ожидания | `canvas.execute` |
| Результаты копируются в наш MinIO; внешние ссылки наружу не отдаются | воркер |
| Старые инструменты `generate.image/video` остаются выключены | `MEDIA_GENERATION_ENABLED=false` |
| Фактическая стоимость от провайдера (`usage.cost`) пишется в `cost_ledger_entry` | воркер |

## 3. Порядок проведения

1. **Предусловия:** задеплоен коммит с 6G; mock-acceptance зелёный (`PHASE6_ALL_PASS`); никаких активных e2e/acceptance.
2. **Открыть окно** (перезапуск api+worker с override, без пересборки):
   ```bash
   bash infra/scripts/staging-6g-window.sh open
   ```
   Проверить вывод: `AI_MOCK_MODE=false`, `PROVIDER_LIVE_EXECUTION_ENABLED=true`, `CANVAS_LIVE_GENERATION_ENABLED=true`, `CANVAS_LIVE_MAX_SECONDS=5`, `MEDIA_GENERATION_ENABLED=false`.
3. **Запустить прогон** (один раз, без повторов):
   ```bash
   bash infra/scripts/staging-playwright-e2e.sh /var/www/ai.shotbro.ru-src phase6g-live
   ```
4. **Закрыть окно сразу после прогона — при любом результате:**
   ```bash
   bash infra/scripts/staging-6g-window.sh close
   ```
   Проверить: `AI_MOCK_MODE=true`, `PROVIDER_LIVE_EXECUTION_ENABLED=false`.
5. **Отчёт:** строки `6G_STEP` / `6G_REPORT` из лога, фактические суммы из `cost_ledger_entry` (`entry_type='ACTUAL'`, `mock=0`), ссылки на ассеты в проекте.

**Аварийная остановка:** `staging-6g-window.sh close` (или любой обычный деплой) — возвращает тестовый режим за ~30 с; уже отправленное провайдеру задание доработает у провайдера, но воркер не начнёт новых.

## 4. Критерии успеха

- все 5 шагов `COMPLETED`, ассеты в MinIO нужных типов (PNG/JPEG, MP4, MP3);
- клип ≤ 5 с, озвучка ≈ 3–4 с;
- сумма по `ACTUAL` ≤ $1, каждая операция ≤ своей цены в карточке (±провайдерские округления);
- после закрытия окна флаги вернулись, mock-регрессия не затронута.

## 5. Если шаг упал

Не повторять «вслепую». Записать `failureCode`, ответ провайдера (без ключей), закрыть окно, исправить, затем — отдельный прогон только упавшего шага.

Повторные окна переиспользовали готовые шаги (`E2E_6G_PROJECT_ID`) — за кадры и клип второй раз не платили. Цены в карточке совпали с фактом.

**Что выяснилось и исправлено:**
1. `heygen/avatar-iv` не принимает `frame_images` — фото передаётся как `input_references` (исправлено, `72557c4`). Неизвестные поля провайдер отклоняет без списания.
2. Ошибки провайдера терялись («failed») — теперь в задании код и HTTP-статус (`72557c4`).
3. ElevenLabs при сбое молча отдавал пустой каталог — теперь ошибка; HTML-страница блокировки вместо API переключает запрос на прокси (`2e510af`).

**Блокеры — нужно действие владельца аккаунтов:**
1. **ElevenLabs:** у API-ключа включён список разрешённых IP. Прямой доступ со staging блокируется по региону (HTML-страница), через прокси `31.207.5.233` ответ `403 "The IP address used to make this request is not allowed for this API key"`. Нужно добавить `31.207.5.233` в allowlist ключа (или снять ограничение).
2. **OpenRouter:** остаток баланса ≈ **$0.89** (`total_credits 190`, `total_usage 189.11`). Видео с аватаром отклонено с `402 Payment Required`. С этого же баланса работает агент в чате — при нуле остановится и он. Нужно пополнение.
